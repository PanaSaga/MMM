# MMM 프로젝트 작업 지침

AI 에이전트와 사람 작업자 모두를 위한 작업 규칙입니다. 인수인계할 때 이 문서를 함께 넘겨 주세요.

## 저장소 구조

- Git 저장소 루트: `C:\Project\MMM`
- Unity 프로젝트 루트: `C:\Project\MMM\MMM` (이 문서가 있는 위치)
- Unity 버전: 6000.3.19f1
- 메인 브랜치: `webproto`
- 작업 브랜치: `LKH`

## 에이전트 작업 규칙

1. **커밋 금지 (별도 지시 없을 때)**
   - 사용자가 명시적으로 요청하지 않으면 `git commit`, `git push`를 하지 않습니다.
   - 변경 사항은 작업 트리에 남겨 두고, 무엇을 바꿨는지 보고만 합니다.

2. **`LKH` 브랜치에서 작업 (별도 지시 없을 때)**
   - 작업을 시작하기 전에 현재 브랜치가 `LKH`인지 확인합니다 (`git branch --show-current`).
   - 다른 브랜치에 있다면 임의로 전환하거나 새 브랜치를 만들지 말고, 사용자에게 먼저 알립니다.
   - 사용자가 다른 브랜치를 지정한 경우에만 그 브랜치에서 작업합니다.

## Unity MCP

- 설정 파일: `.mcp.json` (이 폴더)
- Unity 에디터에서 MCP for Unity 브리지가 켜져 있어야 연결됩니다. 연결이 안 되면 에디터가 열려 있는지, 브리지가 실행 중인지 먼저 확인하세요.
